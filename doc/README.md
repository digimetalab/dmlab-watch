## Ringkasan

- **Grid CCTV 3×3 landscape** yang mengisi penuh jendela browser.
- **Pilih kamera** per sel dari daftar atau peta interaktif (Leaflet/OSM).
- **Profil layout** — simpan beberapa susunan 3×3, profil terakhir diingat.
- **Autoplay**, tema **dark/light**, mode **fullscreen**, dan **logging** lengkap.
- Data kamera (109 unit) di-scrape dari API publik ATCS Kota Denpasar ke SQLite.
